# 2클래스 검출기 — 반자동 라벨링·학습 가이드 (온디바이스 인식의 핵심)

## 왜 다시 2클래스인가 (실물 실험 결론)

- 온디바이스 파이프라인은 **책등검출 → 라벨크롭 → OCR** 순서다.
- 실물 서가로 검증한 결과, **OCR은 청구기호를 잘 읽지만(conf 1.00) 크롭이 지저분하면 실패**한다.
  - 스티커가 **3줄(408 / 뉴884 / 권차)** + 옆 "연고" 카테고리 코드·아래 "400" 띠·옆 책 스티커가 크롭에 섞임.
  - 얇은 책은 한 크롭에 라벨 2개가 겹쳐 들어옴.
- 그래서 **YOLO가 "청구기호 라벨"만 타이트하게 잘라줘야** 한다 → 검출기를 2클래스로 만든다.

```
검출(YOLO 1회, 2클래스) → 라벨/제목 깨끗한 크롭 → OCR → 장서 대조
```

## 1차 실패와 교훈

- 1차: `auto_label.py`가 **기하학적 %("하단 72~90%=라벨")**로 라벨을 찍음 → 실제 스티커 위치와 안 맞아 검출기가 헛것을 배움 → 인식 실패(2/58).
- 교훈: **라벨을 실제 위치에서 뽑아야** 한다.

## 2차(현재): 크림색 라벨 분리 기반 반자동 라벨링

`auto_label.py`를 개선했다. 이제 **크림색 청구기호 라벨(저채도·고명도)을 이미지에서 실제로 찾아** call_label 박스를 타이트하게 만든다. 사람은 처음부터 그리지 않고 **틀린 것만 수정**한다.

### 준비된 것
- `dataset_v2/` — 39장(삼송 서가 여러 각도 + 800 문학 서가) + **사전라벨(pre-label)** 407개씩
- `dataset_v2.zip` — Roboflow 업로드용 (YOLO 포맷: images + labels + data.yaml)
- `dataset_v2/preview/*.jpg` — 사전라벨 눈으로 확인용 (빨강=call_label, 파랑=title)

### 라벨 기준 (수정할 때 이대로)
| 클래스 | 박스로 감쌀 것 | 주의 |
| :--- | :--- | :--- |
| `call_label` | **청구기호 라벨(크림/흰 스티커)만** — 숫자·저자기호가 있는 그 사각형 | 위 "연고" 코드·아래 "400/800" 색 띠·옆 책 스티커 **제외**. 타이트하게 |
| `title` | 책등의 **제목 텍스트 영역** (세로 제목 띠) | 제목 글자만. 라벨과 겹치지 않게 |

> 뉴턴 서가는 사전라벨이 거의 정확하다. **800 문학 서가처럼 라벨 모양이 다른 곳은 빨강 박스가 색 띠에 걸치니 꼭 수정**할 것.

## 2. Roboflow에서 수정 → 학습

1. **roboflow.com** 로그인 → Create New Project → **Object Detection**, 클래스 이름 `call_label`, `title`
2. Upload → **`dataset_v2.zip`** 드래그 (이미지+사전라벨 함께 임포트됨)
3. Annotate: 각 이미지에서 위 기준대로 **박스 미세 조정** (대부분 크기만 살짝, 800 서가는 다시)
4. Generate Version → Export → **YOLOv8/YOLO26 포맷** → `dataset.zip` 다운로드
5. **`train_2class_colab.ipynb`** 를 Colab(T4 GPU)에서 실행 → `best.pt`(2클래스) 다운로드
6. `best.pt`를 `libar-sample/`에 넣기

> Roboflow 없이 바로 학습해도 됨: `dataset_v2` 그대로 `train_2class_colab.ipynb`에 올리면 사전라벨로 학습(수정 안 한 만큼 정확도↓). 검증용으로 빠르게 돌려볼 때 유용.

## 3. 학습된 검출기로 최종 인식

`best.pt`(2클래스)를 넣고:
```
python libar_batch.py shelf_4558.jpg --catalog books_4558.csv
```
검출기가 라벨을 타이트하게 잘라주면 배치 OCR 정확도가 올라간다.
(현재 일반 엔진 `libar_ondevice.py`는 크림분리 크롭으로 35~46/58 인식 — 2클래스 검출기로 크롭이 깨끗해지면 개선 여지가 여기다.)

## 대림 적용
- 대림 서가 사진 확보 → `python auto_label.py 대림*.jpg --out dataset_daelim` → Roboflow에서 수정 → 이 데이터 추가 후 재학습(파인튜닝)
- 장서는 솔로몬 export로 `--catalog` 교체
