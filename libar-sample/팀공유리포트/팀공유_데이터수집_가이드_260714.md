# LibAR 데이터 수집 가이드 (260714)

오늘 수집분 520조각을 전수 분석해서 만든 가이드입니다. 결론 먼저:
**"반 발짝 가까이, 여러 구간을, 가끔은 판독 모드로"** — 이 세 가지면 됩니다.

## 1. 거리 — 한 화면에 책 10~15권

가장 중요합니다. 실측 결과 라벨이 화면에 크게 잡힐수록 학습 가치가 가파르게 올라갑니다:

| 화면 속 라벨 크기 | 학습 가치 (조각당) |
|---|---|
| 멀리서 (한 화면 20권 이상) | 기준 |
| **한 화면 10~15권** | **1.6배** |
| 한 화면 7~8권 | 2.3배 |

너무 가까우면 한 번에 담는 책이 줄어드니, **"한 칸(한 단)의 절반쯤이 화면에 차게"**가 균형점입니다.

## 2. 구간 — 골고루가 보약

지금까지 조각이 005(컴퓨터)·673.5(음악) 두 구간에 몰려 있습니다. AI가 "흐릿하면 005처럼 찍는" 편식이 생겨서, 이번 학습(v5)이 실패한 원인 중 하나였어요.
- **아직 없는 구간 우선**: 200·300·400·500·800번대
- 같은 구간을 여러 번보다, **한 번씩이라도 여러 구간**이 훨씬 좋습니다
- 라벨 색이 다른 구간(파랑·초록·보라·검정·빨강)을 다양하게 담으면 검출기 학습에도 보약

## 3. 모드 — 수집 모드가 기본, 가끔 판독 모드

- **수집 모드(📦)**: 평소 기본. 빠르고(3~5초) 양을 모읍니다. 정답은 저희가 나중에 장서 목록으로 붙이는데, 이 자동 정답은 정확도 ~90%라 아주 약간의 오답이 섞입니다.
- **판독 모드(일반 스캔)**: 하루 몇 번, 여유 있을 때. 느리지만(40초+) 앱이 그 자리에서 정답을 확정하기 때문에 **최고 품질 정답**이 붙습니다. 특히 비슷한 청구기호가 몰린 구간(005.13/005.130/005.133 같은)은 판독 모드가 꼭 필요합니다.
- 비율 감각: **수집 8 : 판독 2** 정도면 충분합니다.

## 4. 촬영 요령

- 라이브 수집은 4초마다 자동 저장됩니다 — **한 자리에서 1~2초 멈췄다가** 옆으로 이동
- 서가와 **정면으로 마주 보기** (비스듬하면 라벨이 눌려 보여 가치가 떨어짐)
- 형광등 반사가 라벨을 덮으면 반 걸음 옆에서
- 화면 위 "📦 전송 N개" 숫자가 늘고 있으면 정상 작동 중

## 5. 하지 않아도 되는 것

- 같은 칸을 여러 번 왕복 (한 번이면 충분)
- 일부러 흔들리지 않게 숨 참기 (4초 자동 수집이 알아서 안정된 프레임을 고릅니다)
- 전송 확인 기다리기 (실패해도 다음 스캔 때 자동 재전송)
