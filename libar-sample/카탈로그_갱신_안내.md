# 장서 카탈로그 갱신 절차

앱의 장서 데이터(대조·오배열 판정·도서찾기의 기준)는 스냅샷이라, 대출·반납·신간이
쌓이면 낡습니다. 낡으면 "대출 중 발견" 오탐과 신간 미등록이 늘어나므로 **격주(권장)
또는 서가점검 전날** 갱신합니다.

## 1단계 — 광수쌤: 엑셀 추출 (5분)

자관 전산에서 **3층 종합자료실 전체 장서**를 엑셀로 내려받아 드라이브(또는 카톡)로
전달해 주세요.

- 범위: 종합자료실 전체 (000~999, 배가상태 필터 걸지 말 것 — 전체 상태 포함)
- 열: 시스템이 주는 **전체 열 그대로** (최소한 배가상태·청구기호·자료실명·서명·저작자·ISBN 포함)
- 7/14에 주셨던 "종합 장서 데이터(000-999).xlsx"와 같은 방식이면 됩니다

※ 상태(제적·분실·파손 등)를 미리 거르지 않아도 됩니다 — 변환기가 겁니다.

## 2단계 — 아인: 변환 (1분)

```
cd libar-sample
py -3.12 make_catalog.py "..\대림데이터\새엑셀.xlsx"
```

- 출력에서 **권수 변화(신규/사라짐)** 확인 — 갱신 기록으로 남기기
- 안전장치: 이전 대비 5% 이상 급감하면 부분 추출로 보고 자동 중단(`--force`로만 무시),
  이전판은 `webdemo/demo/catalog_prev.json`으로 자동 백업
- 산출: `webdemo/demo/catalog.json`(앱 탑재분 — call/title/sec/room만, 내부 관리필드 제외)
  + `catalog_full.csv`(위험도 분석용, gitignore)

## 3단계 — 아인: 게이트 후 배포

```
cd libar-sample/webdemo/tests
node run_all.mjs          # 13종 전부 PASS일 때만 배포
```

PASS면 공개 리포에 카탈로그만 교체:

```
# libar-demo 클론에서
cp <프로젝트>/libar-sample/webdemo/demo/catalog.json demo/catalog.json
git add demo/catalog.json && git commit -m "장서 카탈로그 갱신 (YYYY-MM-DD 추출, N권)" && git push
```
