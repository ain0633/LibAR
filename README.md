# LibAR — 도서관 빅데이터 × 책등 인식 기반 실시간 AR 서가 관리·탐색 시스템

스마트폰 카메라로 서가를 비추면, AI가 책등을 탐지하고 청구기호를 판독하여
**사서에게는 오배열 도서(빨강)를, 이용자에게는 찾는 책(초록)을** 화면에 실시간 표시하는 웹 서비스.
축적된 오배열 로그를 전국 대출 빅데이터와 결합 분석해 서가 운영을 최적화한다.

> **2026 도서관 데이터 활용 공모전** 출품작 (서비스 아이디어 제안 부문) · 실증 대상: 영등포구립 대림도서관

## 진행 상황 (2026-07-18~20)

- **A안 고해상 원샷 현장 실증 (아이폰 16 Pro, 대림 39분)**: 원샷 4K 작동 확인 → jetsam 크래시로 2560 안정화(간격 18초). 수집 조각 높이 중앙값 66→**257px(4배)**, 청구기호 확정률 2%→**44%** — "성능은 픽셀에서 나온다" 실측
- **위험군 한정 제목 대조 배포**: 라벨만으로 특정 불가한 위험군 413권(전체 2% — 꼬리숫자 시리즈+접두 분류쌍·동일저자)만 제목 줄을 추가 판독해 확정. 보수 설계(명확할 때만 교체, 미발동 시 기존과 동일) — 성능 하락 원천 차단, 대조 1회 ~0.2초
- **발열 4카드 배포 (판독률·속도 무손실 설계)**: 검출 가동률 41%→30%(휴식 450ms) → 이동·대기 중 18%(유휴 감속) → 결과 검토 중 0%(가려진 검출 휴면) + 전처리 낭비 제거(패딩 재변환 삭제·LUT, 텐서 비트 동일 검증)
- **rec v8 기각 = 파인튜닝 라인 최종 종결 (4연속)**: 원샷 고해상 재료(사람 라벨 410줄+순서 추론 91줄, 모델 독립 GT)로도 전 그룹 하락 — 병목이 오염→편향→정보량→**학습량**까지 전부 소거됨. 남은 자산: 공정 현장 평가셋 2벌(76+101줄) = 향후 모든 변경의 판정 잣대
- **검출기 v5 기각**: 박스 완화+하드 네거티브로 검출 지표는 우세(재현율↑·오탐 30%↓)나 **판독 E2E가 14→12권** — 판독 스택이 v3 박스 통계에 튜닝된 결합 실증. 교훈: 검출기 교체는 검출 지표가 아니라 판독 E2E로 판정
- **순서 추론 자동 정답 개통**: 서가 위치+카탈로그 유일 후보 게이트 = 검증 정밀도 100%(273/273) — 사람 라벨링 없는 GT 채널. 사람 라벨링 도구(label.html)로 누적 788줄 + 전산-서가 불일치 실물 6건 발견(원고 소재)
- **다음**: 공모전 원고(8/7) · 현장 판독 불만족 진단(리포트 기반 정량 분해) · 사서용 사진 점검 모드 검토(12MP 정지 촬영 = 원샷 대비 픽셀 3배) · 행 문맥 게이트(고립 분류 오탐 강등, 현장 확인 후)

## 파이프라인 (현재 실증 구현 기준)

**하이브리드 (판정 메인, `daelim_yolo_pipeline.py`)**
```
사진 → ① YOLO 라벨 검출 → 줄(밴드) 구성 + 기울기 회전 보정
     → ② 줄 스트립 OCR (×3 업스케일 + 청크 분할, det가 텍스트 줄 검출)
     → ③ 토큰 x배정 + 클러스터 채널 (미검출 라벨 회수 안전망)
     → ④ 장서목록 대조 (청구기호 직독 + 제목 이중 대조로 복구)
     → ⑤ LIS 오배열 판정 → ⑥ AR 오버레이 (🟢직독 🔵제목복구 🔴오배열 ⚪미판독)
```

**온디바이스 (웹앱, `webdemo/app.html`)** — 위 구조에서 ①~⑤를 브라우저 ONNX로 이식
(직독 전용 + 위험군 413권 한정 제목 대조 · rec fp16 48MB + mobile det 4.5MB · 동적 검출: 라이브 960px/사진 1280px
· WebGPU/WASM 자동 선택 · 대조 20,944권 전 장서 · 수집 모드 `#collect`
· 결과 리포트: 판독 화면+판정 목록 한 장 합성 → 팀 드라이브 전송, 점검 기록 보존
· A안 고해상 원샷: 판독 순간만 ImageCapture/해상도 승격으로 최대 픽셀 확보, 실패 시 기존 프레임)

**휴리스틱 (걷기 스캔 챔피언, `daelim_closeup.py`)** — 라벨 색상 자동탐지 + 숫자 앵커 분권,
걷기 동영상 판독률 95% (검출기 v4가 따라잡는 것이 다음 과제)

- **라벨 우선(Label-first):** 책 생김새가 아니라 청구기호 라벨을 읽음 → 판본·개정판·커버 변수 회피
- **숫자 앵커:** 색 스티커 위 흰 숫자 하나가 물리적 책 한 권의 표지 — 붙어 있는 얇은 책 분리·미판독 책 자리 확보·권수 검산에 사용
- **이원화 OCR:** 저해상 라벨 전용 파인튜닝 모델(합성 5,883장 학습)과 큰 글자에 강한 기존 모델을 영역별로 나눠 적용
- **이중 대조:** 라벨이 잘리거나 훼손돼도 책등 제목 OCR로 복구
- **LIS 판정:** 인접 비교가 아닌 최소 오배열 집합만 지목 (이웃 오탐 방지)
- **멀티프레임 합산:** 여러 컷의 인식 결과를 투표로 합산 — 인식률 상승(63→102권) + 오배열 오탐 필터
- **적용 범위:** spine-out 단행본 서가 (그림책·비정형 배가는 향후 과제) · 책등/라벨 탐지의 YOLO26n 전환은 로드맵 M3
