# LibAR — 도서관 빅데이터 × 책등 인식 기반 실시간 AR 서가 관리·탐색 시스템

스마트폰 카메라로 서가를 비추면, AI가 책등을 탐지하고 청구기호를 판독하여
**사서에게는 오배열 도서(빨강)를, 이용자에게는 찾는 책(초록)을** 화면에 실시간 표시하는 웹 서비스.
축적된 오배열 로그를 전국 대출 빅데이터와 결합 분석해 서가 운영을 최적화한다.

> **2026 도서관 데이터 활용 공모전** 출품작 (서비스 아이디어 제안 부문) · 실증 대상: 영등포구립 대림도서관

## 파이프라인 (현재 실증 구현 기준)

**하이브리드 (판정 메인, `daelim_yolo_pipeline.py`)**
```
사진 → ① YOLO 라벨 검출 → 줄(밴드) 구성 + 기울기 회전 보정
     → ② 줄 스트립 OCR (×3 업스케일 + 청크 분할, det가 텍스트 줄 검출)
     → ③ 토큰 x배정 + 클러스터 채널 (미검출 라벨 회수 안전망)
     → ④ 장서목록 대조 (청구기호 직독 + 제목 이중 대조로 복구)
     → ⑤ LIS 오배열 판정 → ⑥ AR 오버레이 (🟢직독 🔵제목복구 🔴오배열 ⚪미판독)
```

**온디바이스 (웹앱, `webdemo/app.html`)** — 위 구조에서 ①~⑤를 브라우저 ONNX로 이식
(제목복구 제외, 직독 전용 · rec fp16 48MB + mobile det 4.5MB · WebGPU/WASM 자동 선택)

**휴리스틱 (걷기 스캔 챔피언, `daelim_closeup.py`)** — 라벨 색상 자동탐지 + 숫자 앵커 분권,
걷기 동영상 판독률 95% (검출기 v4가 따라잡는 것이 다음 과제)

- **라벨 우선(Label-first):** 책 생김새가 아니라 청구기호 라벨을 읽음 → 판본·개정판·커버 변수 회피
- **숫자 앵커:** 색 스티커 위 흰 숫자 하나가 물리적 책 한 권의 표지 — 붙어 있는 얇은 책 분리·미판독 책 자리 확보·권수 검산에 사용
- **이원화 OCR:** 저해상 라벨 전용 파인튜닝 모델(합성 5,883장 학습)과 큰 글자에 강한 기존 모델을 영역별로 나눠 적용
- **이중 대조:** 라벨이 잘리거나 훼손돼도 책등 제목 OCR로 복구
- **LIS 판정:** 인접 비교가 아닌 최소 오배열 집합만 지목 (이웃 오탐 방지)
- **멀티프레임 합산:** 여러 컷의 인식 결과를 투표로 합산 — 인식률 상승(63→102권) + 오배열 오탐 필터
- **적용 범위:** spine-out 단행본 서가 (그림책·비정형 배가는 향후 과제) · 책등/라벨 탐지의 YOLO26n 전환은 로드맵 M3
